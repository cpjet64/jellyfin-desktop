# Tahoe FFmpeg library build proposal

This proposal covers the source libraries for Intel macOS Tahoe, SDK 26.5 and Apple clang 21. The host's CMake, Ninja, pkgconf and Python are observed prerequisites for this proposal; their exact identities and compatibility must be recorded with the eventual build evidence. It excludes the application helper. It is not a completed lock or an executable build script: per-component standard-argument expansions, installation paths, runtime linkage and artifact checks still require resolution. No sources were downloaded or built for this document.

The source URLs, SHA-256 values, x264 Git revision, source provenance, libvpx patch and test-resource distinction are listed in [macos-ffmpeg-components.md](macos-ffmpeg-components.md). The source baseline is Homebrew core `c38a4a58b06912c3e64e5afd7f7dfe8aedd84dc5`. Verify every source against that inventory before use; a Git revision is not an archive hash. NASM 3.02 and Meson 1.12.1 are pinned build-tool sources in that inventory; Meson uses host Python and Ninja here. No Python formula, Python resources, or Homebrew's pkgconf head-only muon resource are required by this custom proposal. CA certificates are a non-linkage OpenSSL input and their trust installation remains unresolved.

## Edges and sequence

FFmpeg declares pkgconf, dav1d, LAME, libvmaf, libvpx, OpenSSL, Opus, SDL2 compatibility, SVT-AV1, x264, x265, xz and Intel NASM. dav1d and libvmaf require Meson, Ninja and NASM; libvpx and x264 require NASM; SVT-AV1 and x265 require CMake and NASM; LAME declares pkgconf and mpg123; SDL2 compatibility requires CMake and SDL3; SDL3 requires CMake and pkgconf. OpenSSL uses Perl and declares CA certificates without linkage. macOS supplies FFmpeg's bzip2 and libxml2 and libvmaf's xxd.

Prepare host tools, NASM and Meson first. Build mpg123 before LAME and SDL3 before SDL2 compatibility. Build the other libraries after their tools, then configure and build FFmpeg last. Use an isolated, absolute installation prefix and ensure pkgconf and the linker search only the intended inputs. This is a proposed order, not evidence of successful builds.

## Formula-derived command specification

Each command below describes a step in a future script, executed from the corresponding verified source tree. `PREFIX`, `OPENSSL_ETC`, `MAN`, and `RPATH` are placeholders that must be resolved before execution. Set compiler, SDK, architecture, deployment target, build and link flags consistently. The separately pinned [build conventions](macos-library-build-conventions.md) document common Homebrew helper defaults and proposed substitutions; component overrides, environment shims and runtime CPU detection must still be expanded and verified. The main proposal limits concurrency to two compile jobs and one component at a time.

1. NASM: `./configure --prefix=PREFIX`, then `make install`. Meson 1.12.1 must be made available using the verified host Python; its installation method remains to be selected.
2. mpg123: `./configure --with-module-suffix=.so --enable-static --with-default-audio=coreaudio --with-cpu=x86-64` plus resolved standard configure arguments; `make install`.
3. LAME: set `ac_cv_prog_cc_c23=no` and append `-Wno-implicit-function-declaration` to C flags; run `./configure --disable-dependency-tracking --disable-debug --prefix=PREFIX --enable-nasm`, then `make install`.
4. dav1d: `meson setup build` plus resolved standard Meson arguments; `meson compile -C build --verbose`; `meson install -C build`. libvmaf uses `meson setup build libvmaf` with the same sequence and installs its `model` directory to package share.
5. libvpx: apply the pinned formula's inline `:DATA` patch; in a `macbuild` directory run `../configure --prefix=PREFIX --disable-dependency-tracking --disable-examples --disable-unit-tests --enable-pic --enable-runtime-cpu-detect --enable-shared --enable-vp9-highbitdepth --target=x86_64-darwin25-gcc`, then `make install`. Confirm the target against the actual Tahoe kernel before execution.
6. OpenSSL: `perl ./Configure --prefix=PREFIX --openssldir=OPENSSL_ETC --libdir=lib darwin64-x86_64-cc enable-ec_nistp_64_gcc_128`; `make`; `make install MANDIR=MAN MANSUFFIX=ssl`. The formula links its configured `cert.pem` to the CA bundle after installation; the custom trust path must be decided and tested.
7. Opus: `./configure --disable-doc` plus resolved standard configure arguments; `make install`.
8. SDL3: replace `@SDL_PKGCONFIG_PREFIX@` in `cmake/sdl3.pc.in` with the chosen prefix, then configure with `-DSDL_TESTS=OFF -DSDL_X11_XTEST=OFF` plus resolved standard CMake arguments; build and install. SDL2 compatibility uses CMake with `-DCMAKE_INSTALL_RPATH=RPATH` pointing to SDL3, builds and installs, and creates `sdl2.pc` as a symlink to `sdl2-compat.pc`. The formula distinguishes its global configured prefix from its install prefix; reconcile this with the isolated prefix before scripting.
9. SVT-AV1: CMake configure with `-DCMAKE_INSTALL_RPATH=RPATH` plus resolved standard CMake arguments; build and install.
10. x264: `./configure --prefix=PREFIX --disable-lsmash --disable-swscale --disable-ffms --enable-shared --enable-static --enable-strip`; `make install`.
11. x265: configure and build `source` into `10bit` with `-DENABLE_HDR10_PLUS=ON -DHIGH_BIT_DEPTH=ON -DEXPORT_C_API=OFF -DENABLE_SHARED=OFF -DENABLE_CLI=OFF`; move its `libx265.a` to `8bit/libx265_main10.a`. Configure and build `12bit` with `-DMAIN12=ON` and the same high-bit-depth flags; move its archive to `8bit/libx265_main12.a`. Configure `8bit` with `-DLINKED_10BIT=ON -DLINKED_12BIT=ON -DEXTRA_LINK_FLAGS=-L. -DEXTRA_LIB=x265_main10.a;x265_main12.a -DCMAKE_INSTALL_RPATH=RPATH` and standard CMake arguments. Preserve the semicolon as one argument. Build, rename its static archive to `libx265_main.a`, combine the three archives with macOS `libtool -static -o libx265.a`, and run `make install` from `8bit`. Resolve generator compatibility with this final `make` step.
12. xz: `./configure --disable-silent-rules --disable-nls` plus standard configure arguments; `make check`; `make install`.
13. FFmpeg: configure with `--prefix=PREFIX --enable-shared --enable-pthreads --enable-version3 --cc=CC --host-cflags=HOST_CFLAGS --host-ldflags=HOST_LDFLAGS --enable-ffplay --enable-gpl --enable-libsvtav1 --enable-libopus --enable-libx264 --enable-libmp3lame --enable-libdav1d --enable-libvmaf --enable-libvpx --enable-libx265 --enable-openssl --enable-videotoolbox --enable-audiotoolbox`; `make install`. The formula also runs `make alltools` and installs executable tools and `tools/python`; decide whether this library-scoped deliverable needs them. Its conditional `-Wl,-ld_classic` applies only to linker versions 1015.7 through 1022.1; inspect the actual linker before deciding.

## Feature and offline failure gates

The listed options reproduce explicit formula arguments, not a complete feature policy. Configure and CMake defaults may detect libraries, frameworks, programs, CPU features, documentation generators or test dependencies from the host. A future script must define an allowlist of intended inputs, isolate discovery to the approved prefix and macOS SDK, and record each component's configure summary and resolved dependency paths. Compare those outputs with an independently specified expected feature set; stop if a required feature is missing, an unapproved dependency appears, or a component silently disables a requested feature. Do not accept a successful exit alone as proof of the requested FFmpeg features.

In particular, FFmpeg's explicit `--enable-ffplay` makes a working SDL2-compatible interface part of the formula configuration; SDL2 compatibility's SDL3 runtime dependency and its runtime search path need direct verification. The FFmpeg argument list does not explicitly enable xz, bzip2 or libxml2, so their effective detection must be inspected rather than inferred from declared dependencies. Likewise, Homebrew's CMake, Meson and configure standard arguments and any upstream defaults determine shared versus static outputs and other features not spelled out above. Freeze the intended linkage and component options before implementing the script; do not silently substitute a host library or remove a codec when detection fails.

The proposed build must not acquire sources or dependencies implicitly. Acquire and verify all approved bytes in a separate authorized step, then run extraction, configuration, compilation, installation and tests without network access. Disable or pre-supply upstream subprojects, wrap downloads, package-manager restores and CMake fetch mechanisms where applicable; fail if a build attempts access or requires an unlisted input. Capture the applied libvpx patch from the pinned formula and verify its identity and application. The source inventory does not establish whether any upstream build system will attempt a network fetch, so offline success remains unproven.

Before building, fail if the host is not the intended Intel Tahoe target, the selected SDK is not 26.5, the selected compiler is not the verified Apple clang 21, any required tool or approved input is absent, or a source digest or x264 revision differs. Determine Darwin kernel and linker versions from the actual host: the `x86_64-darwin25-gcc` libvpx target depends on that evidence. The formula appends `-Wl,-ld_classic` only when ld64 is between 1015.7 and 1022.1 inclusive; the observed linker version is not established here. Stop on configure, compile, test or installation failure, unexpected paths or linkage, missing required artifacts, or storage exhaustion. Record exact command arguments and outcomes without claiming the proposal ran.
