# FFmpeg stack path and environment audit

Static inspection of stable Intel macOS formulae in homebrew-core `c38a4a58b06912c3e64e5afd7f7dfe8aedd84dc5`. This records formula-visible operations, not expansion of Homebrew shims or proof of the host build. Build systems can embed additional paths; inspect their generated metadata and binaries before declaring relocation successful. The custom isolated-prefix proposal in [macos-library-ffmpeg-lock.md](macos-library-ffmpeg-lock.md) deliberately does not claim Homebrew path equivalence.

| Formula | Path, environment, or generated-output behavior | Custom-build difference or gate |
| --- | --- | --- |
| FFmpeg | Supplies formula prefix and Homebrew `ENV.cc`, `ENV.cflags`, `ENV.ldflags` as configure host flags. Appends `-Wl,-ld_classic` only for ld64 1015.7–1022.1. Installs executable `alltools` outputs to bin and `tools/python` to package share. | Resolve actual compiler/flags/linker and explicit install prefix; decide whether alltools and Python support are required. Inspect binaries and pkg-config output for build-path leakage. |
| dav1d | Uses Homebrew standard Meson arguments. | Expand equivalent prefix, library directory, build type and other standard settings; do not assume Meson defaults match. |
| LAME | Sets `ac_cv_prog_cc_c23=no`; appends `-Wno-implicit-function-declaration`; passes formula prefix. | Preserve these flags deliberately and record actual compiler environment. |
| libvmaf | Meson source subdirectory is `libvmaf`; standard Meson arguments; installs `model` directory to package share. | Model destination and runtime needs must be resolved; do not treat installed library alone as equivalent. |
| libvpx | Calls Homebrew runtime CPU detection; passes formula prefix and macOS architecture/kernel target; applies inline formula patch. | Verify Tahoe kernel target and patch bytes; independently establish equivalent CPU flags without host-specific accidental tuning. |
| OpenSSL | `--prefix` is formula prefix, `--openssldir` is package configuration directory, `--libdir=lib`; installs manpages to formula man path. Post-install links package `cert.pem` to global `etc/ca-certificates/cert.pem`; preserves `certs` and `private` directories. | A single isolated prefix is a different layout. Define certificate/config locations and trust behavior and check installed config, provider modules, symlink targets and relocation. Do not overwrite host trust configuration. |
| Opus | Uses standard configure args with `--disable-doc`. | Expand standard prefix and build flags; stable source does not run head-only `autogen.sh`. |
| SDL3 | Replaces `@SDL_PKGCONFIG_PREFIX@` in `cmake/sdl3.pc.in` with `HOMEBREW_PREFIX` before CMake; uses standard CMake args. | Choose actual common prefix and verify generated `.pc` paths rather than substituting an arbitrary package staging directory. |
| SDL2 compatibility | On macOS sets install rpath to SDL3's formula opt library. Configures standard CMake args with `install_prefix: HOMEBREW_PREFIX`, installs with formula `prefix`, and creates `sdl2.pc` symlink to `sdl2-compat.pc`. | The configure and install prefixes intentionally differ in Homebrew. A custom layout must choose both explicitly, preserve the pkg-config alias, and verify runtime SDL3 loading and relocation; copying Homebrew's opt path is insufficient. |
| SVT-AV1 | Calls Homebrew runtime CPU detection; passes computed install rpath and standard CMake args. | Fix and verify runtime CPU policy and rpath for the isolated layout. |
| x264 | Passes formula prefix directly. | Verify generated config and library install names for the selected prefix. |
| x265 | Calls Homebrew runtime CPU detection, uses computed rpath and standard CMake args for three builds; moves 10-bit and 12-bit static archives into 8-bit build and combines them with macOS `libtool`. | Preserve build-directory-relative archive paths and quote the semicolon in `EXTRA_LIB` as a single argument. Inspect final combined archive and shared-library install names. |
| xz, mpg123 | Use standard configure arguments; mpg123 explicitly selects CoreAudio and x86-64. | Expand prefix and flags rather than assuming defaults; verify target architecture and library metadata. |
| NASM | Stable configure explicitly passes formula prefix. | Record actual tool path and architecture; avoid silently picking a different host assembler. |
| Meson | Pip installation uses Homebrew standard args with build isolation. After installation it rewrites `/usr/local` to `HOMEBREW_PREFIX` in `compilers/mixins/apple.py`, `coredata.py`, `dependencies/{boost,cuda,misc,qt}.py`, `mdevenv.py`, `options.py`, `scripts/python_info.py`, `utils/universal.py` and bash completion; rewrites `/opt/homebrew` in `dependencies/{boost,misc}.py` and `compilers/mixins/apple.py`; changes `'/var/local` in `options.py` to Homebrew var. | Host-Python Meson installation is not equivalent unless its isolated build inputs, prefix, search behavior and rewrites are explicitly resolved. Do not assume pip build isolation works offline. Verify dependency discovery stays within approved paths. |
| pkgconf | Stable configure embeds search paths for `HOMEBREW_PREFIX/{lib,share}/pkgconfig`, `/usr/local/lib/pkgconfig`, `/usr/lib/pkgconfig` and Homebrew's OS-version-specific macOS pkgconfig directory; specifies SDK `/usr/include` and `/usr/lib` as system paths. Installs `pkg-config` and manpage aliases. | Host pkgconf may search unrelated prefixes or lack Homebrew SDK `.pc` files. Record version and compiled defaults, constrain discovery and verify actual queried paths and system-library resolution. |

Homebrew's `prefix`, `opt_prefix`, `HOMEBREW_PREFIX`, `etc`, `var`, `rpath` and standard argument helpers are distinct values; they cannot be replaced mechanically with one placeholder without checking observable behavior. No dependency, network, compiler, or runtime behavior was exercised in this audit. Stop before claiming a lock if the selected prefix, SDK inputs, compiler flags, search paths, generated metadata or runtime library resolution remain unknown.
