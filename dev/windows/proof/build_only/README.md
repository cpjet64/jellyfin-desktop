# Build-only proof policy

This separate protocol does not accept the strict helper receipt. Production
policies are empty pending independent review of an exact command manifest.
Fixture policies cannot provide production evidence. The receipt binds the
independently supplied policy and source to command, root, deadline, job
membership, pinned residual identity, cleanup and fresh output evidence.
The caller must independently observe both successful supervisor exit and a
closed receipt. Its write-complete field is only a serialization assertion.
The selected environment digest includes missing values, without recording
environment values in the receipt. Telemetry identity establishes a file path
and file identity, not the bytes mapped into a running process.

No build, execution, or qualification is authorized by these definitions.
